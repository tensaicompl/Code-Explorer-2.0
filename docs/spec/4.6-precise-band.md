## 4.6.1 Sources

| Language | Indexer | Invocation | Output |
|---|---|---|---|
| Java, Kotlin, Scala | `scip-java` | `scip-java index --output index.scip` inside a build container with Maven/Gradle mirrors configured by `pdx.toml [precise.java]` | `index.scip` |
| TypeScript, JavaScript | `scip-typescript` | `scip-typescript index --output index.scip` after `pdx.toml [precise.ts] install_cmd` | `index.scip` |
| Python | `scip-python` | `scip-python index . --output index.scip` after `[precise.python] install_cmd` | `index.scip` |
| Go | `scip-go` | `scip-go --output index.scip` | `index.scip` |
| C, C++ | `scip-clang` | requires `compile_commands.json` produced by `[precise.cxx] compdb_cmd` | `index.scip` |
| C# | `scip-dotnet` | `scip-dotnet index --output index.scip` | `index.scip` |
| Rust | `rust-analyzer` | `rust-analyzer scip . --output index.scip` | `index.scip` |
| Ada, SPARK | `pdx-ada-indexer` (ours, 4.6.3) | `pdx-ada-indexer --project <gpr> --output index.scip` | `index.scip` |

The indexers are not bundled in the `pdx` binary. The server runs them in a
**precise-build container image** (`deploy/images/precise-<lang>.Dockerfile`, P5-01)
that contains the indexer and the toolchain; air-gapped sites build these images
against their internal mirrors. Locally, `pdx index --precise` uses whatever indexer
is on `PATH` and reports which ones it found.

## 4.6.2 Enablement

A repository opts in through `pdx.toml` at its root:

```toml
[precise]
enabled = true
languages = ["java", "typescript"]
[precise.java]
build_cmd = "mvn -q -DskipTests package"     # run before scip-java if the build needs generated sources
[precise.ts]
install_cmd = "npm ci --ignore-scripts"
[precise.cxx]
compdb_cmd = "cmake -S . -B build -DCMAKE_EXPORT_COMPILE_COMMANDS=ON"
timeout_minutes = 90
```

Without `[precise] enabled = true`, no precise job runs and the segment's
`meta.precise_sources` is `[]`.

Precise `build_cmd`/`install_cmd`/`compdb_cmd` are repository-controlled code and are
treated as hostile. They run only in the precise container as non-root with a
read-only root filesystem, dropped capabilities, the default seccomp profile, explicit
CPU/memory/time limits, an ephemeral checkout, no Kubernetes service-account token, no
PostgreSQL, object-store or Git-host credentials after checkout, and default-deny
egress (`PDX_PRECISE_ALLOW_NETWORK=1` opens only the configured mirrors). If the
sandbox cannot be provided, the precise job is marked `blocked` and structural indexing
continues (D34).

## 4.6.3 Ada indexer

`ada-indexer/` is a Python 3.12 program using the `libadalang` bindings. It is packaged
and licensed separately; P0-02 records the actual licence of the pinned libadalang
release in `bench/references.lock`, and the process boundary is kept regardless
(toolchain and crash isolation, and Part 3.4 if the licence requires it). It walks a GPR
project, and for every reference it can resolve (`p_referenced_decl` / `p_xref`) emits a
SCIP `Occurrence` with `symbol_roles`, using SCIP symbol syntax
`scip-ada <package> <unit>/<decl>().` so that the merge step (4.6.4) needs no
Ada-specific code. Unresolved references are emitted as diagnostics so coverage can
count them. The indexer must run without network access.

## 4.6.4 Merge algorithm (precise into structural)

Input: a `structural` segment and one or more `index.scip` files for the same commit.

1. Load the index; for each `Document`, map `relative_path` to `files.path`; count
   unmapped and duplicate documents in `coverage.by_band.unmapped_precise_docs` (a
   coverage-only key). Convert every provider range to **source byte offsets** using the
   provider's declared position encoding (UTF-8/UTF-16/UTF-32) and normalised line
   endings; line/column proximity is never used for matching.
2. For each `Occurrence` with the `Definition` role, map to our node by exact byte-range
   overlap of the definition's name span plus a compatible kind; if more than one node
   remains, record `ambiguous_definition_mapping` in `evidence.metadata` and map
   nothing. Keep a `scip_symbol → node_id` map. Definitions we lack become new nodes
   with `props.origin = "precise"` only when the provider supplies kind, name and range
   sufficient for a deterministic `node_id` (`symbol_to_qn`, P5-02).
3. A provider **reference is not a call**. For each reference-role `Occurrence`, find the
   `sites` row of kind `call` whose byte span intersects the occurrence; only if exactly
   one such site and exactly one mapped target exist: if our drawn edge at that site has
   the same `dst` → band `precise`; if it has a different `dst` → the old edge becomes
   `contradicted` (kept, with an `evidence` row `contradicts` naming the provider target)
   and a `precise` edge is inserted; if we had a `candidates` row → insert a `precise`
   edge and delete the candidate; if we had nothing → insert a `precise` edge.
   Occurrences that intersect no call site (reads, writes, imports, type references)
   update `USES_TYPE`/`READS_FIELD`/`WRITES_FIELD`/`IMPORTS` edges at their own sites by
   the same rule and every occurrence, matched or not, is stored in
   `semantic_occurrences` with its mapped target, role and intersecting site;
   `pdx_references` enumerates that table in the precise profile and falls back to
   structural sites (`edges` joined with `sites`) in the structural profile, labelling
   which one it used.
4. Provider relationships (implementation, type definition, override) create or upgrade
   `IMPLEMENTS`, `OVERRIDES` and `USES_TYPE` edges where both endpoints map uniquely.
5. Every upgrade, insertion and contradiction writes an `evidence` row with provider,
   version, verdict and byte span; two precise providers disagreeing on one site write
   `conflict` rows and neither target is drawn as `precise`.
6. Recompute `coverage.by_band`.
7. Write a new segment with `profile = 'precise'` and `meta.precise_sources` listing the
   tools, versions and container digests used. The `structural` segment is left
   unchanged.

A merge that maps fewer than 50% of provider documents fails the job (status `failed`,
reason `precise_mapping_low`).
