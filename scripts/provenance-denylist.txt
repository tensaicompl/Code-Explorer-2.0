# Provenance deny-list.
#
# The canonical list of strings that may not appear in this tree. Used by
# scripts/provenance-scan.sh to fail the build, and by scripts/plan/extract-plan.py
# to redact prose extracted from the plan document.
#
# One regular expression per line, case-insensitive; blank lines and lines
# starting with # are ignored. These are the identifiers of the vendored and
# ported references: names, URLs, product names, maintainer handles and upstream
# symbol prefixes. They may appear in the external plan document; they may not
# appear anywhere in this tree except THIRD_PARTY_NOTICES.md and the LICENSE
# files inside vendored directories.
#
# This file is the scanner's own input and is therefore excluded from the scan.
#
# Extend, never shorten: when unsure whether a string is provenance, treat it as
# provenance.
#
# A line is a regular expression, optionally followed by a tab and the text that
# replaces it when vendored sources are sanitised. The scanner reads the pattern and
# ignores the replacement; the vendoring rename step uses both, so that what the scan
# forbids and what the rename removes cannot drift apart. Without a replacement the
# rename step substitutes a neutral placeholder.
